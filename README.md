# Beam Balance - Demo Materials for App Review

## Demo Video
https://github.com/rankunduanduan/beam_balance_demo/releases/download/V1.0/demo.mov

## What this app does
Beam Balance is an educational physics simulator that reproduces 
a laboratory pan balance for students to practice weight selection 
and vernier scale reading.

## Video contents 
1. Place the object on the left pan
2. Add weights (1g/2g/5g/10g/20g) to the right pan
3. Move the rider until the balance is level
4. Read the result: object mass = weights + rider reading
5. New a record dialog, type in experiment data and summary
6. View history and open the record, use transparency slider & collapse button
7. Share the record to an email address
